🔗 RLC-Reihenschaltung (Serienresonanz)
Reihenschaltung

Schaltung & Formeln

In der Reihenschaltung fließt durch alle Bauteile derselbe Strom I. Die Spannung teilt sich auf.

Z = √(R² + (XL − XC)²) [Ω] ← Gesamtimpedanz I = U / Z [A] ← Strom (gleich durch alle) UR = I · R [V] UL = I · XL [V] UC = I · XC [V] cos φ = R / Z ← Leistungsfaktor φ = arctan((XL − XC) / R) ← Phasenwinkel

Verhalten nach Dominanz

XL > XCinduktiv — Strom eilt Spannung nach · φ > 0°
XC > XLkapazitiv — Strom eilt Spannung vor · φ < 0°
XL = XCResonanz — Z = R (minimal), I = U/R (maximal), cos φ = 1

Serienresonanz

f0 = 1 / (2π · √(L · C)) [Hz] ← Resonanzfrequenz Bei f = f₀: XL = XC → Z = R (min) → I = U/R (max)
Merke: Bei Serienresonanz kann UL oder UC größer als die Gesamtspannung U sein! Die Teilspannungen heben sich auf, aber einzeln können sie sehr hoch sein (Spannungsresonanz).

Berechnungsbeispiel

📖 Beispiel: R = 30 Ω, XL = 70 Ω, XC = 30 Ω, U = 250 V
XL − XC= 70 − 30 = 40 Ω
(XL − XC)²= 40² = 1.600
R²= 30² = 900
Z = √(900 + 1600)= √2500 = 50 Ω
I = U / Z = 250 / 50= 5 A
cos φ = R / Z = 30 / 50= 0,60 (induktiv)
⚡ RLC-Parallelschaltung (Parallelresonanz)
Parallelschaltung

Schaltung & Formeln

In der Parallelschaltung liegt an allen Bauteilen dieselbe Spannung U. Der Strom teilt sich auf.

IR = U / R [A] ← In Phase mit U IL = U / XL [A] ← eilt U um 90° nach IC = U / XC [A] ← eilt U um 90° vor Iblind = |IL − IC| [A] ← Blindstrom Iges = √(IR² + Iblind²) [A] ← Gesamtstrom cos φ = IR / Iges ← Leistungsfaktor

Verhalten nach Dominanz

IL > ICinduktiv — Gesamtstrom eilt Spannung nach
IC > ILkapazitiv — Gesamtstrom eilt Spannung vor
IL = ICResonanz — Z = R (maximal), I = IR (minimal), cos φ = 1

Parallelresonanz

f0 = 1 / (2π · √(L · C)) [Hz] ← gleiche Formel wie Serie! Bei f = f₀: IL = IC → Iges = IR (min) → Z = max
Merke: Im Parallelschwingkreis können IL und IC sehr viel größer als Iges sein! Sie heben sich auf, zirkulieren aber als großer Strom im Kreis (Stromresonanz).

Berechnungsbeispiel

📖 Beispiel: R = 50 Ω, XL = 25 Ω, XC = 100 Ω, U = 200 V
IR = 200 / 50= 4 A
IL = 200 / 25= 8 A
IC = 200 / 100= 2 A
Iblind = IL − IC = 8 − 2= 6 A (induktiv)
Iges = √(4² + 6²) = √52≈ 7,21 A
cos φ = 4 / 7,21≈ 0,555
🔧 Blindleistungskompensation
Kondensator parallel

Warum kompensieren?

Induktive Verbraucher (Motoren, Transformatoren) haben einen niedrigen Leistungsfaktor (cos φ < 1). Das führt zu:

  • Unnötig hohem Strom in den Leitungen → Spannungsabfall und Verluste
  • Mehrkosten durch Blindleistung beim Netzbetreiber
  • Überlastung von Transformatoren

Lösung: Kondensator parallel zum Verbraucher schalten. Der kapazitive Blindstrom des Kondensators kompensiert den induktiven Blindstrom des Verbrauchers.

Berechnung der Kompensation

QC = P · (tan φ1 − tan φ2) [var] C = QC / (ω · U²) = QC / (2π·f·U²) [F] φ1 = Ausgangs-Phasenwinkel (vor Kompensation) φ2 = Ziel-Phasenwinkel (nach Kompensation)

Berechnungsbeispiel

📖 Beispiel: P = 5 kW, cos φ₁ = 0,7 → cos φ₂ = 0,95, U = 230 V, f = 50 Hz
sin φ₁ = √(1 − 0,7²) = √0,51≈ 0,714
tan φ₁ = 0,714 / 0,7≈ 1,020
sin φ₂ = √(1 − 0,95²) = √0,0975≈ 0,312
tan φ₂ = 0,312 / 0,95≈ 0,329
QC = 5000 · (1,020 − 0,329)≈ 3.455 var
C = 3455 / (2π · 50 · 230²)≈ 208 µF

Arten der Kompensation

EinzelkompensationKondensator direkt beim einzelnen Verbraucher — höchste Wirkung, aber teurer
GruppenkompensationKondensator für eine Gruppe von Verbrauchern — guter Kompromiss
ZentralkompensationEin großer Kondensatorsatz für die gesamte Anlage (Hauptverteilung) — günstig, aber weniger wirksam für einzelne Leitungen
📐 Die 5 Dreiecke im Wechselstromkreis
Widerstand · Leitwert · Spannung · Strom · Leistung

Im Wechselstromkreis gibt es fünf rechtwinklige Dreiecke — alle geometrisch ähnlich mit demselben Phasenwinkel φ. Alle folgen dem Pythagoras-Prinzip:

Hypotenuse² = Wirkseite² + Blindseite² cos φ = Wirkseite / Hypotenuse sin φ = Blindseite / Hypotenuse tan φ = Blindseite / Wirkseite
① Widerstands­dreieck
Reihenschaltung [Ω]
Z = √(R² + X²) cos φ = R / Z
② Leitwert­dreieck
Parallelschaltung [S]
Y = √(G² + B²) cos φ = G / Y
③ Spannungs­dreieck
Reihenschaltung [V]
U = √(U_R² + U_X²) cos φ = U_R / U
④ Stromdreieck
Parallelschaltung [A]
I = √(I_R² + I_X²) cos φ = I_R / I
⑤ Leistungs­dreieck
Reihe & Parallel
S = √(P² + Q²) cos φ = P / S

Das Leitwertdreieck im Detail

Das Leitwertdreieck ist das „Kehrwert-Dreieck" zum Widerstandsdreieck und gilt für Parallelschaltungen:

Y — AdmittanzScheinleitwert [S] = Kehrwert der Impedanz: Y = 1/Z = I/U
G — KonduktanzWirkleitwert [S] = 1/R = IR/U · verbraucht Wirkleistung
BL — Suszeptanz LInduktiver Blindleitwert [S] = 1/XL = IL/U
BC — Suszeptanz CKapazitiver Blindleitwert [S] = 1/XC = IC/U
Y = √(G² + B²) mit B = |BL − BC| G = IR / U = 1 / R [S] BL = IL / U = 1 / XL [S] BC = IC / U = 1 / XC [S] cos φ = G / Y

Wie hängen die Dreiecke zusammen?

Die Dreiecke sind untereinander direkt verknüpft. Multipliziert man das Widerstandsdreieck mit dem Strom I, erhält man das Spannungsdreieck. Multipliziert man mit I², erhält man das Leistungsdreieck:

Widerstandsdreieck × I → Spannungsdreieck R · I = UR X · I = UX Z · I = U Widerstandsdreieck × I² → Leistungsdreieck R · I² = P X · I² = Q Z · I² = S Widerstandsdreieck ÷ Z² → Leitwertdreieck R / Z² = G X / Z² = B Z / Z² = Y = 1/Z
Merke: Alle Dreiecke haben den gleichen Winkel φ — deshalb gilt cos φ überall gleich: immer Wirkseite durch Hypotenuse.
