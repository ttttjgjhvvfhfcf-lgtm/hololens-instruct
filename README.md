# hololens-instruct

## watt champion – Rennoberfläche für den Raspberry Pi

Im Ordner [`watt-champion/`](watt-champion/) liegt eine Oberfläche für einen Energie-Wettkampf
zwischen zwei Spielern (Leistung in W, Energie in mWh, Rennstrecke, Rennzeit, Rekord), gedacht für
einen Raspberry Pi mit Bildschirm im Kiosk-Modus. Anleitung, Konfiguration und Sensor-Anschluss:
[`watt-champion/README.md`](watt-champion/README.md).

```bash
cd watt-champion && python3 server.py   # dann http://127.0.0.1:8080/ öffnen (Simulation)
```
