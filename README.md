# hololens-instruct

## watt champion – Rennoberfläche für den Raspberry Pi

Im Ordner [`watt-champion/`](watt-champion/) liegt eine Oberfläche für Energie-Wettkämpfe (Energie- oder
Zeit-Rennen, Solo oder 1 vs 1) mit Leistungsanzeige, Rennstrecke, Leistungskurve, Rekorden und
Bildschirmtastatur, gedacht für einen Raspberry Pi mit Bildschirm im Kiosk-Modus. Anleitung,
Konfiguration und Sensor-Anschluss: [`watt-champion/README.md`](watt-champion/README.md).

Ausprobieren ohne Installation: `watt-champion/static/index.html` in Chrome öffnen (Demo-Modus mit Simulation).
Mit Server: `cd watt-champion && python3 server.py` und `http://127.0.0.1:8080/` öffnen.
